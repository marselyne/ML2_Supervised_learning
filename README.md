# ML2 — Supervised Learning

Проект по машинному обучению, посвящённый реализации и сравнению алгоритмов линейной регрессии и регуляризации.

## 📌 О проекте

В рамках проекта были реализованы и исследованы модели supervised learning для задач регрессии.

Основной акцент сделан на:
- собственной реализации Linear Regression через SGD
- сравнении с моделями из scikit-learn
- исследовании регуляризации
- анализе метрик качества
- работе с preprocessing данных

---

## 🚀 Реализованный функционал

### 📈 Linear Regression
- собственная реализация Linear Regression
- обучение через SGD (Stochastic Gradient Descent)
- вычисление метрик качества
- сравнение с sklearn

### 📊 Регуляризация
Реализованы:
- Ridge Regression
- Lasso Regression
- ElasticNet

Для каждой модели:
- обучение
- сравнение метрик
- подбор параметров
- анализ переобучения
